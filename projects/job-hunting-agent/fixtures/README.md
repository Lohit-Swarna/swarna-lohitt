# Test fixtures

Synthetic inputs for the container smoke test in CI. Jane Doe is a fictional candidate and the job description was written for this test; neither is real personal or employer data.

| File | Purpose |
|---|---|
| `sample-cv.pdf` | One-page text PDF CV, generated by `node fixtures/make-sample-cv.mjs` |
| `sample-jd.txt` | Job description asking for SQL, Python, Power BI and AWS |

Expected API result for this pair: four bullets returned unchanged, with the Python bullet first, and `missingSkills` equal to `["aws"]`.
