# Job Hunting Agent

A small Next.js web app that compares a CV (PDF) with a pasted job description. It returns a match score, the CV's own bullet points ordered by relevance to the job, the job-description skills the CV does not mention, and a draft cover letter.

**Stage:** in development. It runs locally and in Docker, with automated tests, a production build and a container smoke test in CI. There is no hosted demo, user study or adoption claim.

## What it does and does not do

| Feature | Behavior |
|---|---|
| CV parsing | Extracts text from an uploaded PDF (5 MB limit) with `pdf-parse`. Scanned/image-only PDFs have no text layer and are not supported. |
| Keyword extraction | Rule-based: a fixed list of 33 technical skills matched as whole words, responsibility/qualification lines found by pattern, plus capitalized words. No language model is used. |
| Tailored bullets | Reorders the candidate's own bullets so those mentioning job-description skills come first. **Bullet wording is never changed**, so the output cannot claim experience the CV does not contain. |
| Skill gaps | Lists job-description skills that the CV never mentions, with a reminder to add one only if it is true. |
| Match score | 0–100: skills (40), capitalized keywords (30), responsibilities (30). A rough heuristic, not a hiring prediction. |
| Cover letter | Fills a fixed template with the company, role, up to two matched skills and the name at the top of the CV. Treat it as a first draft. |
| Tracker row | Returns a date/company/role/link/score row for a job-tracking sheet. Writing to Google Sheets is **not** implemented. |

The CV is processed in memory for the request and is not stored. The server logs processing errors, not CV text.

## Run it

Requires Node.js 22.18 or newer (CI uses Node 24).

```bash
cd projects/job-hunting-agent
npm ci
npm run dev          # http://localhost:3000
```

Production build: `npm run build && npm start`.

Docker (standalone Next.js server, runs as the unprivileged `node` user):

```bash
docker compose up --build   # http://localhost:3000
```

## Checks

```bash
npm run lint
npm run typecheck
npm test             # Node's built-in test runner on lib/*.test.ts
npm run build
```

CI (`.github/workflows/portfolio.yml`) runs these, plus `npm audit --omit=dev --audit-level=high`, then builds the Docker image, starts it and posts the synthetic [fixture CV](fixtures/README.md) to `/api/process`, checking the response.

## Architecture

```
app/page.tsx              Client UI: upload, job description form, results
app/api/process/route.ts  POST endpoint: validates input, runs the pipeline below
lib/pdfProcessor.ts       PDF → text
lib/processing.ts         Keyword extraction, bullet ordering, skill gaps, match score
lib/coverLetter.ts        Cover letter template
lib/googleSheets.ts       Tracker-row formatting
```

## Revision notes (November 2026)

The first version was generated by an AI coding agent and merged while CI was failing. This revision:

- Removed `google-auth-library-nodejs`, an npm security placeholder for a removed package, and five other unused dependencies (`axios`, `jspdf`, `pdfmake`, `googleapis`, a duplicate `pdfjs-dist`). Updated Next.js to 16.4.3. `npm audit --omit=dev` went from 12 vulnerabilities (2 critical) to 0.
- Fixed bullet rewriting, which produced text such as "Develop aws pythoned web applications… (Senior) (Software)" and inserted skills the CV did not mention.
- Fixed skill matching that used substrings (`java` matched "JavaScript", `ai` matched "maintain") and never matched `c++`.
- Fixed a global-regex bug that skipped every other responsibility line, and a scoring bug that credited responsibilities for shared `-` bullet characters.
- Fixed PDF parsing in production builds (the pdf.js worker was missing from the bundle).
- Added upload type/size limits, generic client error messages and the always-visible job description field (the "JD Link" mode was never wired up).
- Replaced the console-only test script with 18 assertion-based tests, and the Node 18 Dockerfile (unsupported by Next.js 16) with a Node 24 standalone image.

## Known limitations

- The skill list is fixed and short; "Power BI", "pandas" or "Tableau" are not recognized as skills.
- Capitalized-word keywords include section words such as "Required" or "Responsibilities".
- Responsibility matching compares the first three meaningful words of each line, so wording differences are missed.
- No authentication or rate limiting; run it locally or behind your own access control.
