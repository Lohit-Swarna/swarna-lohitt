# Portfolio visual assets

| Asset | Purpose | Provenance / checks |
|---|---|---|
| `assets/portfolio-banner.svg` | Identity, three professional domains and concise engineering theme | Original vector asset for this rebuild; system fonts, navy/teal palette, descriptive title/alt text, no remote dependencies, scripts or animation |
| `assets/portfolio-banner.png` | Reliable GitHub README display | 1920 × 480 PNG export of the vector source; desktop and mobile preview checked; no external image service |

The previous `chat.svg` and contribution-snake SVG were removed from the current tree after source review. They were animated decorative assets with no accessible title/description or project evidence; the chat also contained stronger professional claims than the published evidence supported. Their original history remains in Git, and a pre-redesign bundle was preserved locally. The existing non-default branch was retained unchanged.

Typography uses Helvetica, with the viewer's standard fallback when unavailable. The banner supplements readable Markdown; essential information is repeated in text. Do not replace project evidence with contribution streaks, vanity statistics or invented client results.
