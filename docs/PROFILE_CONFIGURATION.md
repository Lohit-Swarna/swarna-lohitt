# Portfolio hub and GitHub profile display

`swarna-lohitt` is the retained central portfolio repository. The current account username is `Lohit-Swarna`. GitHub automatically displays a profile README only from a public repository matching the username, with a nonempty root README. Therefore this repository's README renders as a portfolio hub but is not automatically the account-home README. [GitHub profile README requirements](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme).

The current scope keeps only this public portfolio repository and does not authorize an account rename or another repository. Those are separate decisions. The hub can be shared directly at `https://github.com/Lohit-Swarna/swarna-lohitt`; pinning or editing account profile fields is also separate from repository-file publication.

This rebuild did not change account security, visibility, private repositories or username settings. The account was independently observed under its current username before publication, with the same immutable account and repository IDs. Existing non-default branch history was preserved rather than merged into the portfolio without validation.
